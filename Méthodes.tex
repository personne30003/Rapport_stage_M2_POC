De manière générale, nous allons résoudre les équations suivantes \textbf{Illisible, mets une seule couche !!} : 
\begin{align}
	\dT{q_o}+\mathrm{J}(\psi_o, q_o) = \frac{1}{R_{d, o}^2}\mathrm{J}(\psi_o, \theta_o) + C_{w, a} \triangle_\mathrm{h} (\psi_o - \psi_a) \, | & \, \dT{q_a}+\mathrm{J}(\psi_a, q_a) = \frac{1}{R_{d, a}^2}\mathrm{J}(\psi_a, \theta_a) + C_{w, a} \triangle_\mathrm{h} (\psi_a - \psi_o)\\
	\dT{\theta_o} + \mathrm{J}(\psi_o, \theta_o) = -C_t(\theta_a -\theta_o) \, | &\, \dT{\theta_a} + \mathrm{J}(\psi_a, \theta_a) = -C_t(\theta_o -\theta_a) \\
	q_o = \triangle_{\mathrm{h}}\psi_o -\frac{\psi_o - \theta_o}{R_{d, o}^2} + \beta y \,|&\, q_a = \triangle_{\mathrm{h}}\psi_a -\frac{\psi_a - \theta_a}{R_{d, a}^2} + \beta y
	\label{eq:sys_TQG}
\end{align}
Dans une configuration fermée, les vitesses normales sont nulles sur tous les bords, ce qui donne : 
\begin{align}
	u(0, y, t) = u(L_x, y, t) = 0 \Rightarrow \partial_y \psi(0, y, t) = \partial_y \psi(L_x, y, t) = 0 \\
	v(x, 0, t) = v(x, L_y, t) = 0 \Rightarrow \partial_x \psi(x, 0, t) = \partial_y\psi(x, L_y, t) = 0  
\end{align}

Dans une configuration \guillemets{canal} zonal, seule la vitesse normale $v$ est nulle sur les bords verticaux. Cela revient à fixer la valeur de $\psi$ : 
\begin{align}
	\psi(x, 0, t) = T_0(t) \\
	\psi(x, L_y, t) = 0
\end{align} 
Où $T_0(t) = \int_0^L u(x, y, t) \mathrm{d}y = -\int_0^L\partial_y u(x, y, t) \mathrm{d}y = -(\psi(x, L, t) - \psi(x, 0, t))$ est le transport zonal.

\subsubsection{Généralités sur les méthodes pseudo-spectrales}
\textbf{Intérêt, avantage par rapport aux différences finies, principe de base. Se baser sur \cite{Trefethen2000}. Pourquoi utiliser une base de fonctions et pas une autre ?}
De manière générale, pour calculer numériquement la dérivée d'une fonction définie sur un intervalle discrétisé, deux techniques existent : les différences finies, et les méthodes  pseudo-spectrales.\textbf{Nous faisons abstraction des éléments/volumes finis !}.

 La méthode des différences finies consiste à estimer localement la dérivée par un développement de Taylor. Par exemple, un schéma centré (avec un développement de Taylor à l'ordre 2) donne, pour les dérivées premières et secondes :  
\begin{align}
	\frac{\partial f}{\partial x}|_{x_i}\approx\frac{f(x_{i+1}) -f(x_{i-1})}{2\Delta x} \\
	\frac{\partial^2 f}{\partial x^2}|_{x_i}\approx\frac{f(x_{i+1}) + f(x_{i-1}) - 2f(x_i)}{\Delta x^2}
\end{align}
Aux bords du domaine, les opérateurs sont approximés différemment (par exemple à l'aide de points fictifs), en tenant compte des conditions aux limites.La précision d'un schéma en différences finies dépend de l'ordre du développement de Taylor utilisé. L'obtention d'une forte précision nécessite généralement d'augmenter l'ordre du schéma ou de diminuer $\Delta x$.

Les méthodes pseudo-spectrales \cite{Trefethen2000}, \cite{Boyd} consistent au contraire à interpoler une fonction $f$ sur une base de fonctions $\psi_k$ (supposées orthogonales) : 
\begin{equation}
	f(x) \approx \sum_{k=0}^N \hat{f}_k \psi_k(x_i)
\end{equation}
La dérivation est alors effectuée en dérivant analytiquement les fonctions de base $\psi_k$ :
\begin{equation}
	\frac{\partial f(x_i)}{\partial x} = \sum_{k=0}^N \hat{f}_k \psi'_k(x_i)
\end{equation}
Selon la base choisie, les fonctions $\psi_k$ peuvent être définies par récurrence, et l'équation précédente deviens matricielle : 
\begin{equation}
	\frac{\partial f(x_i)}{\partial x} = D f(x_i)
\end{equation}
Où $D$ est une matrice de différenciation.
La difficulté consiste à savoir quelle base utiliser, et comment déterminer les coefficients $\hat{f_k}$. Ceux-ci dépendent notamment des conditions aux bords. Ces méthodes restent néanmoins plus performantes que les différences finies, tant en rapidité qu'en précision. C'est pour cela que nous avons choisi de les utiliser. Pour des frontières périodiques, nous utilisons la base de Fourier (fonctions trigonométriques), tandis que pour des frontières bornées, nous utilisons la base de Chebyshev (polynômes).

\subsubsection{Méthodes de Fourier}
La base de Fourier est constituée de fonctions trigonométriques, périodiques sur l'intervalle $[0, 2\pi]$ : 
\begin{equation}
	\hat{v}_k = \sum_{j=1}^N e^{-ikx_j}v_j\, , \, k = -\frac{N}{2}+1,...,\frac{N}{2},\, x\in [0, 2\pi]
\end{equation}
Où $N$ est un entier pair. Le passage dans cette base s'effectue avec l'algorithme de la Transformée de Fourier Rapide (FFT). La dérivée se calcule alors facilement, puisque la matrice de différenciation dans la base de Fourier est diagonale : 
\begin{equation}
	\hat{D}_{lm}  = ik_l\delta_{ll} 
\end{equation}
Soit 
\begin{equation}
	\frac{\partial f(x_j)}{\partial x}  = \mathrm{FFT^{-1}}[ik \mathrm{FFT}[ f(x_j) ]]
\end{equation}
